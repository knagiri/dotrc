# plan に書かれたツール挙動を検証せず SKILL.md へ書き写した

## 経緯

委譲された実装計画には、追加する SKILL.md の全文が埋め込まれていた。その中に「headless 起動では
`claude-review` が出力をログ化する」という、repo 内のツールの挙動についての主張があった。
委譲先は設計判断と同じ扱いでこれを無検証に書き写し、レビューで事実誤りとして差し戻された。

## 観測

`bin/claude-review` を読むと、ログ化しているのは自身が起こす headless pane の stdout を `tee`
する部分だけだった。委譲先の interactive セッションから呼ばれた skill の出力はそのログに載らない。
計画の主張は、ツールの実装を読まずに類推で書かれていた。

## 直し方

plan の設計判断（何を選ぶか・どこに置くか）には従う一方、plan 本文が repo 内の実装・ツール
挙動に言及していたら、書き写す前に該当ファイルを読んで確かめる、とした。設計をやり直すのとは
別物なので、HOW を作り直さない不変条件とは矛盾しない。
